\section*{LLM Usage Statement}
\label{sec:llm}

A large language model, Claude, was used as a coding assistant in the Cursor IDE to write code and to generate figures.
The code includes the experiment, analysis, and plotting scripts, and the figures and tables are produced by that code from the recorded results.
The model was not used to form the hypothesis, to design the experiments, or to write the text.
The authors reviewed the code and the figures and take full responsibility for the content of the paper.
