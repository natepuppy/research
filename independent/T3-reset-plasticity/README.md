# T3: What does a reset reset? Trainability under prolonged GRPO

**Question.** ProRL keeps RLVR improving by resetting the reference policy and optimizer state. Which component does the work: coverage / the KL anchor, stale Adam statistics, or representational plasticity loss? Does SWD's bootstrapping-based plasticity theory predict anything in a regime with no bootstrapping?

**Status.** Laptop pilot run 14 Oct 2026 (3 seeds, 42 runs). Verdict: `KILL TEST: INCONCLUSIVE` because the positive control (supervised relabelling) did not lose trainability in this testbed. The data nonetheless show an RL-specific trainability loss (−28% probe gain, eNTK rank 41 → 31–35) that none of the resets fixes and temperature re-inflation partially does. The stated hypothesis (stale Adam) is not supported. Full account in `notes/pilot_notes.md`. No paper draft yet.

Loss note: the pilot used a group-sum GRPO loss with β = 0.01; the script now uses group-mean with β = 0.01/G, which is the same problem under Adam.
