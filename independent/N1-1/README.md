# N1-1: Off-policy TD diverges along its symmetric spectrum

**Question.** Semi-gradient TD is not gradient descent: the Jacobian of its expected update splits into a symmetric part and a skew (curl) part. Which part is responsible for divergence, and does it predict divergence in deep RL?

**Status.** Full manuscript drafted (`paper/paper.md`), conference-length version in `paper/paper_rlc.md`. Verdict: `KILL TEST: SUPPORTED` (see `results/verdict.txt`).

## Layout

| folder | contents |
|---|---|
| `code/` | `n1_td_curl.py` (main sweep), `n1_extensions.py`, `n1_deep_envs.py` + `analyze_deep_envs.py` (deep-RL divergence onset), `n1_anchor*.py`, `make_figures.py`; `code/lib/` is the vendored shared library (Baird, chain MDPs, curl and sharpness estimators); `code/probes/` the two probe scripts the paper cites |
| `data/` | empty: every environment is generated by code |
| `results/` | raw CSV/JSON from the scripts, `verdict.txt` |
| `paper/` | `paper.md` (full), `paper_rlc.md` (RLC length), `paper_short.md` (early draft), `figures/` (written by `code/make_figures.py` and `code/analyze_deep_envs.py`) |

## Run

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python code/n1_td_curl.py            # main experiment (--smoke / --full)
.venv/bin/python code/n1_extensions.py
.venv/bin/python code/make_figures.py          # regenerates paper/figures from results/
```
