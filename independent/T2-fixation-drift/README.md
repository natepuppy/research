# T2: Selection vs drift: a fixation theory of rare correct modes under finite-group GRPO

**Question.** Under GRPO with group size G, does a prompt whose correct answer has small base probability p₀ fix (p → 1) or go extinct, and can a Wright–Fisher-style chain, calibrated only on interference measured from held-out prompts, predict which? Does this explain the bimodal pass@k "kernel" reported for RLVR?

**Status.** Laptop pilot run 14 Oct 2026 (3 seeds, 33 runs). Verdict: `KILL TEST: INCONCLUSIVE` on the quantitative calibration (MAE 0.12), but the boundary kernel is bimodal in 87% of cells, fixation rises in log G, adaptive group size helps at matched budget, and the pilot found that cross-prompt interference is *selection against rare modes*, not neutral drift. Full account in `notes/pilot_notes.md`. This is the strongest of the three pilots. No paper draft yet.
