# R3: Preprocessing builds a fictional MDP. Does offline RL's own evaluation fool it?

**Question.** Frost et al. (2602.06603) showed that binning ICU logs to a fixed grid makes FQE over-rate the policy learned on the same binned data by 1.5–3x. The AI Clinician pipeline also clusters states, discretises doses, and carries observations forward. Each step is a map φ from real trajectories to fictional ones, and the pipeline both trains and evaluates inside φ. Is the self-deception specific to time binning, or does every lossy φ do it, and does evaluating on the raw trajectories fix it or only flag it?

**Status.** Laptop pilot run 15 Oct 2026 on the synthetic continuous-time glucose simulator shared with R1 (`code/lib/ctsim.py`), 5 seeds × 18 pipelines. Verdict: `KILL TEST: SUPPORTED` (`results/verdict.txt`). With no lossy map the pipeline is honest (optimism −0.4); merging glucose into 3 bins gives +4.6 to +7.1, into 2 bins +23 to +29, time binning +11 to +49; action coarsening alone is harmless (−1.3). Every binned or binary-state policy deployed worse than the clinician while being reported as better. Raw-log evaluation flags this but cannot fix it off-support. Read `notes/pilot_notes.md`. This is the pilot to build the paper on. Next: the same grid on Frost's UVA/Padova simulator, add imputation and weight-clipping maps, write the φ-invariance condition, and fold in R1's binning sign-flip result.

## Pre-registered kill test (written before the pilot ran; a 1-seed smoke run had been seen)

Pipelines φ = time {raw, bin1h, bin4h} × state {fine (6 glucose bins), coarse (3), binary (2)} × action {fine (5 levels), coarse (3)}. Every φ gets the same offline-RL step (model-based Q-iteration, actions need ≥ 30 visits) and the same FQE on a held-out φ(log). `optimism` = in-φ FQE minus the deployed value; `raw_err` = timing-aware FQE on the raw held-out log minus the deployed value.

- **K1.** (sanity, Frost replication) Binned pipelines' mean optimism exceeds the raw pipeline's by more than 2 at fine state/action.
- **K2.** Among raw-time pipelines, at least two of the five coarser state/action variants have mean |optimism| more than 2 seed-SDs above fine/fine. If this fails, "only binning matters" and the paper is a note.
- **K3.** For binned pipelines, raw-log FQE is closer to the deployed value than in-φ FQE in more than half the runs.

SUPPORTED if K2 and K3 hold. INCONCLUSIVE if exactly one holds. KILLED if neither.
