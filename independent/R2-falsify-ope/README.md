# R2: Falsification tests for off-policy evaluation

**Question.** Applied OPE papers end with "FQE, WIS and DR agree, so we trust the number." Agreement says nothing when the estimators share a bias (same logs, same behaviour model, same preprocessing). Epidemiology has negative controls (Lipsitch 2010; Shi, Miao & Tchetgen Tchetgen 2020) and proximal RL uses them for identification, but nobody uses them as *tests* in sequential OPE. Do log-only falsification tests (behaviour self-evaluation, negative-control outcome, negative-control policy, placebo rewards) catch wrong estimates that the usual checks (agreement, ESS) miss, and which failure mode does each test have power against?

**Status.** Laptop pilot run 15 Oct 2026 on tabular MDPs with a hidden per-episode variable, inert states, and exact ground truth. Verdict: `KILL TEST: KILLED` by the pre-registered rule (`results/verdict.txt`), but two tests clearly work: the negative-control policy catches confounding with power 0.99 (agreement: 0.35) and behaviour self-evaluation catches a miscalibrated behaviour model with power 0.95. Abstraction and support failures were under-injected and K1 scored the tests on variance-driven error, which they are not meant to detect. Read `notes/pilot_notes.md`. Next: harsher abstraction/support injections, a shared-bias setting, failure-presence AUROC instead of K1; then a sepsis simulator and the MIMIC-IV demo pipeline.

## Pre-registered kill test (written before the pilot ran)

Failure modes: `none`, `confounding` (u hidden), `miscal` (behaviour model smoothed toward uniform), `abstraction` (states merged in threes), `support` (target acts where the behaviour never did). Estimators scored: FQE, WIS, DR (IS and PDIS are logged but excluded: at this horizon their effective sample size is ~1%, so they are wrong for variance reasons, which is not what the tests are for). An estimator is **biased** in a configuration if its error averaged over data replicates exceeds 0.5 (returns are on a 0–10 scale) and twice its replicate standard error. Thresholds for every test are set at the 90th percentile of the no-failure configurations (10% false alarm). The **battery** is the max robust z-score over `self`, `nco_is`, `nco_model`, `ncp`, `placebo`; the **standard** checks are the max over `agree`, `ess`.

- **K1.** AUROC of the battery for separating biased from unbiased estimates (all rows) exceeds the standard checks' AUROC by at least 0.10.
- **K2.** For each of confounding, miscal, abstraction, support, at least one battery test has power ≥ 0.6 at 10% false alarm.
- **K3.** (secondary) Agreement has power ≤ 0.2 against confounding (shared bias is invisible to agreement).

SUPPORTED if K1 and K2 hold. INCONCLUSIVE if exactly one holds. KILLED if neither.
